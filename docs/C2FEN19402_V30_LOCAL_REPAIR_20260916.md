## V30 design

The local LP is a bounded candidate generator, not a reduced SCOPF acceptance
model. It uses the current cold run's unchanged primary point, never a prior
run or scenario. Existing exact-parallel and quality-gated within-run routes
remain first. Before the global predictor:

1. Fully rebuild and check the original base for this exact outage. If it is
   feasible and passes the existing native-cost floor, use it directly.
2. Otherwise identify a three-hop neighborhood of the actual outage endpoints
   (or generator bus), using in-service topology with the requested branch
   removed. At most 512 control buses are allowed. A one-hop boundary has
   fixed controls but bounded, penalized imbalance. A too-large neighborhood
   skips this attempt; no source outage is skipped.
3. Make at most two local LP proposals, at most 0.35 s each, with a 0.75 s
   combined cooperative budget including construction and checking. Angle
   and voltage movement is restricted to 0.05 rad / 0.02 p.u. per proposal.
   The original base remains the ramp/commitment anchor. Source PMIN/PMAX,
   Q limits, corrective load bounds, branch constraints and 0.5-p.u. imbalance
   caps are unchanged. The LP's optional, conservative separate P/Q flow
   boxes are off: they are stricter than the actual apparent-flow limits and
   would prevent fixed, already-valid remote branches from remaining fixed.
   All actual linearized branch constraints and full nonlinear checks remain.
4. The LP retains full original linearized rows for its independent audit.
   Controls outside the neighborhood are fixed; outside the boundary, signed
   imbalance is fixed to the reference. Exact fixed-column substitution
   produces the small solver matrix. Constant infeasible rows reject the
   candidate rather than disappearing. The local LP uses fresh single-thread
   HiGHS simplex with presolve and no basis/primal start.
5. Expand the LP result, audit every original row and column, recompute all
   nonlinear AC flows, costs and residuals, then apply the complete original
   AC validator. Accept only finite native objective at or above the existing
   floor `R - 0.01*max(1,abs(R))`. This floor is a work-quality heuristic,
   not a lower bound, global-optimality certificate or MIP gap.
6. Failed/low-quality attempts use the unchanged global predictor/fallbacks.
   No local LP's feasibility alone can certify the contingency. Final success
   still requires exhaustive independent official evaluation of all source
   labels, official infeasibility zero, native residual at most 1e-5 and the
   original 300-second end-to-end boundary.

Compact logs record local attempts, reduced/full dimensions, LP status,
expanded linear residuals, nonlinear residuals, objective, selection and
nested time. Compiler/build, component tests, frozen hashes and run evidence
are recorded below before/after the single experiment, respectively.
