## V5 registered experiment: checked PWL epigraphs

The primary sparse fixed-commitment AC optimizer previously evaluated PWL
generator costs and negative load benefits directly, averaging adjacent slopes
at a breakpoint. V5 adds an opt-in exact epigraph representation. For a signed
source curve with nondecreasing slopes, an auxiliary cost variable is bounded
below by each affine segment, and its positive weighted value enters the
minimized objective. Scaling is algebraic only. Any decreasing slope, nonfinite
coefficient or degenerate segment retains the original representation; no
source curve is convexified or slope-repaired.

Physical variables, bounds (including exact PMIN and source ramp bounds),
physical rows, commitment, and source initialization remain unchanged. Cost
auxiliaries are excluded when converting the NLP vector back to physical
state. Every candidate is rebuilt, rescored using the original source-derived
function, and independently checked before selection. This change does not
make the nonconvex AC problem globally optimal and does not establish a
top-five result without a complete official evaluation.

Configuration `config/c2fen19402_top5_epigraph_v5.json` retains V4's corrective
policy and the 10-second linear / 40-second nonlinear primary allocation.
It registers all five scenarios, the original cold-start contract, the original
source inputs, exhaustive contingencies, and the 300-second end-to-end limit.
The first experiment is one cold scenario-095 run; wider coverage follows only
after assessing that result. The full five-scenario objective remains open.

Pre-run checks: 64 Python tests passed; all four native CTest groups passed
after the final rebuild. Tiny tests compare original and new physical bounds,
starts and rows, map source costs exactly at breakpoints and segment interiors,
reject nonconvex/degenerate source curves, check analytic cost derivatives by
finite differences, and independently validate an optimized tiny state.
The retained V4 full solutions will not initialize this experiment.

## V8 registered experiment: exact sparse Lagrangian curvature

The sparse fixed-commitment AC NLP can now opt into an exact analytic Hessian
of the Lagrangian. Its lower-triangle pattern is constructed once, shared
coordinates from parallel branches are summed, and repeated coordinates from
self-loops are handled with the full symmetric contribution. Curvature covers
nodal balance, fixed shunts, both branch thermal sides and thermal slack;
generator/load bounds, reference/angle rows and the checked PWL epigraph are
linear. The objective is linear after that cost transformation, so its Hessian
is zero. Exact mode refuses any curve that failed the smooth epigraph check.

The first finite-difference test exposed a pre-existing sign error in this
sparse NLP's from-terminal reactive-flow coefficient for phase shifters:
`(b*tr - g*ti)/tap^2` must be `(b*tr + g*ti)/tap^2`. The latter matches complex
power `V * conj(YV)`, the nodal admittance model and the unchanged independent
checker. This is an implementation correction to source physics, not a new
physical formulation. Previously accepted solutions were independently
rebuilt/checked and are not invalidated by an incorrect internal optimizer row.
The experiment therefore measures the combined correction and exact Hessian;
it must not be described as a pure isolated Hessian speedup.

All four native CTest groups and 66 Python tests passed. Tiny fixtures check
the complete Lagrangian Hessian against finite differences of `grad(f)+J'lambda`
for parallel branches, taps/phase shifts/end shunts, transformers, self-loops,
